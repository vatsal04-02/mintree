# Backend Workflow Audit

Method: each requirement of the milestone brief (Part 3) was checked against the code and the automated tests; a rule counts as **proven** only if a test attempts to break it. "Gap" items are listed with what is missing. A module is not marked Complete anywhere in this repository (see `MODULE_COMPLETION_MATRIX.md`).

| Module | Proven (test) | Fixed in this milestone | Gap (not built) |
|---|---|---|---|
| **Inventory** | no over-issue, no double reservation, quarantined stock never dispatched, ledger append-only (trigger), every change transactional, adjustments need a reason and permission, valuation = ledger (`test_inventory_procurement.py`, `test_concurrency.py`, integrity suite) | none needed | production material return to stock; stock-transfer header document; spare-part issues |
| **Procurement** | approval authority and limits, receipts cannot exceed the PO line, duplicate receipts replay, rejected stock unavailable, invoice mismatch refused (three-way match), returns, amendments (`test_purchase_gaps.py`, `test_procurement_returns_amendments.py`, `test_concurrency_finance.py`) | finance concurrency now tested (8 simultaneous invoices bill the received quantity once; two approvers approve once) | per-line delivery schedules |
| **R&D** | 100 % rule, immutable approved versions, production pinned to an approved version (`test_rnd_quality.py`, `test_production.py`) | **formula costing** from stock cost → last PO price → flagged unpriced (`test_cashflow_and_formula_cost.py`) | product-testing beyond trial observations |
| **Production** | material/capacity checks, reservations, issue, stages, wastage with reason, yield, costing, genealogy, concurrent releases never oversell (`test_production*.py`) | none needed | material return, routing master, labour time |
| **Quality** | server-side judgement, failed mandatory test blocks release, rejected batch quarantined for good, retest keeps history, deviation/CAPA, CoA only when released (`test_rnd_quality.py`, `test_quality_sampling_coa.py`) | none needed | inspection-template entity (specs serve) |
| **Dispatch** | allocation ≤ eligible stock, QC-held never shipped, partial shipments reconcile, tracking sequence kept, duplicate webhooks harmless (`test_partial_dispatch.py`, `test_dispatch*.py`) | none needed | replacement shipments, refund flow, live courier APIs |
| **Accounts** | balanced journals (trigger), no silent edits, reversals, allocation ≤ balance, decimal arithmetic, reports reconcile (`test_accounts*.py`, integrity suite) | **cash-flow statement** (direct method, reconciled to the ledger); demo books reconcile to sub-ledgers | GST filing, e-invoicing (not claimed) |
| **CRM / sales** | conversion never duplicates a customer, one-step stage moves, follow-ups actionable, quotation → order (`test_crm_pipeline.py`, `test_sales_dispatch_gaps.py`) | none needed | customer-side acceptance (portal/e-sign) |
| **E-commerce** | idempotent import, duplicate detection, exception queue + retry, settlements with fees posted to the books, returns (`test_e2e_workflows.py`, `test_accounts_gaps.py`) | demo now exercises 126 imports, duplicates, failed sync + retry, settlements across 4 platforms | live Amazon/Flipkart/Myntra/Nykaa adapters (sandbox only, labelled) |

| **Meta / branding** | approval by a different user, one publishing record per item (`test_h5_modules.py`) | **sandbox vs live connections** with DB-enforced "connected only if verified", campaign lifecycle (PAUSED), content SCHEDULED, simulated insights adapter, Graph verification adapter (`test_meta_workspace.py`) | live publishing and live insights (adapter raises `NotImplementedError` rather than pretend) |
| **Platform** | idempotency, outbox, audit, permissions cache, timezone authority | session cache and response cache with epoch/version invalidation (`test_authz_cache.py`, `test_response_cache.py`) | RabbitMQ throughput re-measurement (no broker in this sandbox) |
